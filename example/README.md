# Example static addon

One album of six Chopin recordings by Musopen. The audio is on the Internet Archive (`musopen-chopin`, CC0).

- The album catalog shows the album.
- Search answers only `chopin` and `ballade`. `test` gives an empty answer for the checker.
- Each stream links to the MP3 on `archive.org`.
- It has no cover: the Internet Archive item has no square image.

Copy this folder to make a static addon. The steps are in [docs/guide.md](../docs/guide.md), section 2.
